# MITO

**My Integrated Terminal Orchestrator**, reescrito en Rust.

Port del [MITO original en Python](https://github.com/danielgube/mito): un entorno de
desarrollo de Windows completo y portátil dentro de una carpeta, con profiles,
componentes instalados desde manifiestos Scoop y Windows Terminal privado.

> Estado: en desarrollo. Consulta [docs/PLAN.md](docs/PLAN.md).
